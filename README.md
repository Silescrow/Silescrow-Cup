# SILESCROW CUP

Browser-Fußballspiel – alle Dateien, die das Spiel benutzt, und alle Versionen.

| Ordner | Inhalt |
|---|---|
| `01_Ladebildschirm` | Bilder des Ladebildschirms |
| `02_Hauptmenue_Spielerkarten` | Kartenbilder, getrennt nach Gold / Silber / Bronze / Standard |
| `03_Spielfiguren` | Spieler (vorne, hinten, seitlich, schräg), Schiedsrichter, Zuschauer |
| `04_Geraeusche` | Stadion- und Tor-Geräusche |
| `05_Kommentator` | alle gesprochenen Kommentator-Sätze (B01-02 = Block 1, Satz 2) |
| `06_Spiel` | aktuelles Spiel V 6.3 |
| `07_Dokumente` | Anleitung (LIESMICH), Test-Protokoll, Satzliste |
| `08_Alle_Versionen` | alle Spielversionen, nach V1 bis V6 sortiert (siehe unten) |

Zum Spielen reicht `06_Spiel/SILESCROW_CUP_V6.3.html` – alle Bilder und Töne sind dort eingebaut.
Alles als eine Datei herunterladen: oben **Code → Download ZIP**.
