# SILESCROW CUP

Browser-Fußballspiel 11 gegen 11 – du steuerst alle Feldspieler. Alle Dateien, die das Spiel benutzt, und die aktuelle Version.

| Ordner | Inhalt |
|---|---|
| `01_Ladebildschirm` | Bilder des Ladebildschirms |
| `02_Hauptmenue_Spielerkarten` | Kartenbilder, getrennt nach Gold / Silber / Bronze / Standard |
| `03_Spielfiguren` | Spieler (vorne, hinten, seitlich, schräg), Schiedsrichter; in `Figurenblaetter/` die Originalbilder aus Gemini |
| `04_Geraeusche` | Stadion- und Tor-Geräusche, Musik (Ladebildschirm, Hauptmenü) |
| `05_Kommentator` | alle 667 gesprochenen Kommentator-Sätze (B01-02 = Block 1, Satz 2), Block 1 bis 29 |
| `07_Dokumente` | Satzlisten (Kommentator, Trainer, Presse), Spielerliste, Figuren-Vorlagen und Prompts, Rasen- und Stadionbilder |
| `09_Alle_Versionen` | die Spielversionen; die neueste läuft auch online als `index.html` |

Zum Spielen reicht die neueste Datei in `09_Alle_Versionen` – alle Bilder und Töne sind dort eingebaut.
